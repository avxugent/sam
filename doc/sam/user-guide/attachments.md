# Attachments

Files and links can be attached to both locations and assets. Common uses include installation photos, manuals, invoices, rack diagrams, and links to external resources.

## Viewing attachments

Open the **Attachments tab** on any location or asset detail page. Files show a thumbnail or file icon; links show the URL.

## Uploading a file

1. Go to the Attachments tab.
2. Click **Upload file** or drag and drop a file onto the upload area.
3. Optionally set a **display name** and **description**.
4. Click **Upload**.

**Supported file types:** images (JPEG, PNG, GIF, WebP), PDF, and common document formats.  
**Maximum file size:** 50 MB.

> Requires Editor or Admin role.

## Adding a link

1. Go to the Attachments tab.
2. Click **Add link**.
3. Enter the URL and a display name.
4. Optionally add a description.
5. Click **Save**.

> Requires Editor or Admin role.

## Editing an attachment

Click the **pencil icon** on any attachment to edit its display name, description, or (for links) the URL.

> Requires Editor or Admin role.

## Deleting an attachment

Click the **trash icon** on the attachment and confirm deletion.

> Requires Editor or Admin role.

## Setting a cover image

A location can have one image attachment pinned as its cover — it appears as a banner at the top of the location detail page.

1. Upload or select an existing image attachment on a location.
2. Click **Set as cover** on the image attachment.

To remove a cover image, click **Remove cover** on the location detail page.
