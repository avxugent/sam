# User Guide

This guide explains how to use SAM to manage AV hardware assets across your facilities.

## Pages in this guide

| Page | Description |
|---|---|
| Roles & Permissions | What each role can and cannot do |
| Locations | Browsing, creating, and managing locations |
| Assets | Creating, editing, moving, and decommissioning assets |
| Attachments | Uploading files and adding links |
| Work Logs | Recording maintenance and work history |
| Stock Management | Managing spare inventory and deploying to locations |
| Search & Reports | Finding assets and building custom reports |
| Import & Export | Bulk import from CSV and data export |
| Administration | User management and system settings (Admin only) |
| Profile & Security | Updating your profile and configuring two-factor authentication |

## Getting around

After logging in you land on the **location browser** — a collapsible tree of all your physical spaces. Click any location to open its detail page, where you can see its assets, sub-locations, attachments, and maintenance history.

The **top navigation bar** has a search box (searches all assets and locations), an admin menu (Admin users), and a user menu (profile and sign out).
