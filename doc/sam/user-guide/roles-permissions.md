# Roles & Permissions

Every SAM user is assigned one of four roles. Your role is shown in the user menu at the top right of the screen.

## Role overview

| Role | Who it is for |
|---|---|
| **Viewer** | Read-only access — can browse and search all data |
| **Editor** | Day-to-day management — can create and edit locations, assets, stock, work logs, attachments and reports |
| **Maintainer** | Everything an Editor can do, plus upkeep of the catalog: manufacturers, models and suppliers |
| **Admin** | Full access — manages users, asset types, system settings, imports and exports, and has all Maintainer capabilities |

The **Administration** menu is shown to Maintainers (catalog pages only) and Admins.
